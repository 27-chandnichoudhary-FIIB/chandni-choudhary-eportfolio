## Projects

### 1. MIBC Market Entry Intelligence Tool
- **Problem:** MIBC advisors needed a structured way to assess Mexican brand readiness to enter the Indian market.
- **My contribution:** Sourced and independently verified all underlying data; AI assisted with the code implementation.

- **Output:** Live web app covering 7 Indian cities and 9+ product categories — [market-entry-intelligence-v5.netlify.app](https://market-entry-intelligence-v5.netlify.app)
- **Files:** `evidence/mibc-market-entry-tool/`

### 3. TQMSS Airline Operational Quality Dashboard
- **Problem:** Diagnose where airline service quality was breaking down, using 5,000 flight records.

- **Files:** `evidence/tqmss-airline-dashboard/`

### 4. AUTO-MOTIVE Sales & Service Dashboard (Learning Team 2)

- **Output:** Analyzed 201 car sales (₹336.61M); flagged one model as high-risk (lowest rating, highest complaints) and one region driving the majority of sales.
